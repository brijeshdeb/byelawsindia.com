Screen 7 — Design notes
Typography
Source Sans 3 throughout. Body at 13–15px. Labels at 10–11px uppercase + tracked. All sizes meet WCAG 2.2 minimum contrast on their respective backgrounds.
Rule §3, §31
Touch targets
Bottom nav items and chips are ≥44px tall. Pay button has generous padding. No reliance on hover states — everything is tap-first.
Rule §67–69
Indian number format
Maintenance amount shown as ₹3,200 (Indian number format). Large amounts use lakh notation (₹8.4L).
Rule §89
Senior-citizen usability
No reliance on icons alone — all critical actions have visible text labels. Bottom nav uses both icon + label. Font sizes stay above 12px for all body content.
Rule §70–72
Colour palette
Deep navy (#17324D) for primary UI, accent amber (#C6862C) for the Pay button only. Semantic colours for status (warning for pending dues, success for paid). No gradient backgrounds.
Rule §10–14, §25
No "AI/SaaS aesthetic"
Solid cards with 1px borders, not floating shadow-heavy cards. No greeting emoji. No confetti or celebration illustration. Institutional, not consumer-app.
Rule §1–2, §82–83
Bottom nav limit
5 items — Home, Dues, Complaints, Notices, Profile. Labels are present alongside icons. Badge dots show unread counts.
